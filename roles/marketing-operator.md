# Marketing Operator Guide

## Purpose

Use this guide to prepare traffic, content, and launch support for the partner program.

## Required Read Order

1. START_HERE.md
2. docs/branding/brand-voice.md
3. docs/compliance/guardrails.md
4. docs/funnels/affiliate-funnel-build-spec.md
5. docs/messaging/email-library.md
6. docs/messaging/sms-library.md

## Responsibilities

- Confirm funnel link is ready before posting.
- Use approved brand voice.
- Use approved disclosure language.
- Route prospects to the application page.
- Do not publish draft program terms.
- Coordinate with GHL builder before launch.

## Launch Content Checklist

- Application URL confirmed.
- Landing page mobile view reviewed.
- CTA tested.
- Email sequence ready.
- SMS templates ready.
- Owner review complete.
