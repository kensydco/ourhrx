# AI Operator Guide

## Purpose

Use this guide to configure and test AI assets.

## Required Read Order

1. docs/branding/brand-voice.md
2. docs/ai/knowledge-base.md
3. docs/ai/conversation-ai-spec.md
4. docs/ai/ai-support-spec.md
5. registries/ai-registry.md
6. docs/compliance/guardrails.md

## Responsibilities

- Load approved brand voice.
- Load approved knowledge base.
- Configure Conversation AI.
- Configure phone support AI if used.
- Test common questions.
- Test escalation questions.
- Record QA results.

## Test Questions

- How do I apply?
- What happens after I apply?
- Do I need a large audience?
- Where are my resources?
- I need help with my link.

## Rule

AI should answer only from approved knowledge and route unclear questions to the team.
