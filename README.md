# OurHealth Rx Affiliate Growth Platform

This repository is the implementation playbook for the OurHealth Rx affiliate growth platform.

It documents business architecture, GoHighLevel configuration, affiliate operations, AI prompts, workflows, funnels, reporting, and future companion-app requirements.

## Current Focus

Sprint 1: Foundation and Architecture

## Repository Philosophy

This repo is designed so any operator, contractor, developer, or LLM can understand the system without relying on scattered chat history.

Each implementation document should explain:

1. Business purpose
2. Functional requirements
3. GHL configuration steps
4. AI prompts to accelerate setup
5. QA and acceptance criteria

## Key Platforms

- GoHighLevel: funnels, CRM, automation, AI, email, SMS, affiliate manager, memberships, and reporting
- Native GHL Affiliate Manager: affiliate tracking and commission hub
- Future companion web app: only for gaps GHL cannot solve cleanly
