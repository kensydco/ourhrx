# Sprint 2 GHL Ask AI Prompt Library

## Prompt 1: Campaign

```text
Create a GHL setup checklist for the OHRx Partner Program campaign. Include campaign creation, link setup, application funnel connection, review items, and test steps. Do not invent final program terms.
```

## Prompt 2: CRM

```text
Create a GHL CRM structure for a partner program. Include one pipeline with stages for applicant review, approval, active status, inactivity, rejection, and hold. Include custom fields for niche, audience, platform, social handles, promotion plan, approval date, payout email, tier, count fields, and notes. Create smart lists for each major stage.
```

## Prompt 3: Funnel

```text
Create a three-page GHL partner application funnel for OurHealth Rx. Pages: landing page, application page, confirmation page. Tone: clear, bold, trustworthy, community-centered. Include hero, why join, how it works, who it is for, program value, FAQ, and final CTA. Embed the partner application form on page two.
```

## Prompt 4: Forms

```text
Create GHL forms for a partner program: application, profile update, support request, and resource request. Use clear field labels, required fields where appropriate, and simple confirmation messages.
```

## Prompt 5: Workflows

```text
Create GHL workflows for a partner program: application submitted, pending information, approved, rejected, resource access, inactive 30 days, and inactive 60 days. For each workflow include trigger, tags, pipeline action, message action, owner task, and QA test.
```

## Prompt 6: Messages

```text
Create short email and SMS templates for a GHL partner program. Include application confirmation, approval, pending information, not selected, resource access, check-in, and support follow-up. Keep all messages brief and clear.
```

## Prompt 7: AI

```text
Create GHL AI support assets for the OurHealth Rx partner program. They should answer basic questions, guide users to the next step, create follow-up tasks when needed, avoid inventing terms, and escalate unclear questions.
```

## Prompt 8: QA

```text
Create a launch QA checklist for a GHL partner program. Include foundation objects, form test, funnel test, campaign test, workflow test, email test, SMS test, AI test, mobile view, and owner review.
```
