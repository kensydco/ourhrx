# Sprint 3 GHL Ask AI Prompt Library

## Prompt 1: Resource Vault

```text
Create a GHL membership or gated page structure for an approved partner resource vault. Include sections for start here, program basics, disclosure guide, starter messages, social captions, short video scripts, image assets, FAQ, support request link, and updates. Keep the content simple and action-oriented.
```

## Prompt 2: Onboarding Lessons

```text
Create five short onboarding lessons for approved partners: welcome and first steps, how the program works, disclosure and trust, your first three shares, and weekly rhythm. Keep each lesson clear, practical, and action-oriented.
```

## Prompt 3: Starter Kit

```text
Create a partner starter kit with a quick-start checklist, disclosure examples, three captions, three outreach templates, three story prompts, one FAQ post template, and one weekly rhythm. Keep everything simple and clear. Use placeholders for the partner link.
```

## Prompt 4: Activation Sequence

```text
Create a 14-day GHL activation sequence for approved partners. Include day 0, day 1, day 3, day 5, day 7, day 10, and day 14 messages. Focus on getting the first share, using approved starter content, and building a simple weekly rhythm.
```

## Prompt 5: First 30 Days

```text
Create a first 30 days plan for approved partners. Break it into week 1 launch, week 2 educate, week 3 build rhythm, and week 4 review. Each week should include simple actions and no complex setup.
```

## Prompt 6: Social Content Bank

```text
Create a starter social content bank for approved partners. Include content pillars, three feed captions, three story ideas, two FAQ posts, and one weekly reminder. Use a clear, trustworthy tone and partner link placeholders.
```

## Prompt 7: Support Request

```text
Create a partner support request process in GHL. Include support form fields, support categories, workflow trigger, tag, task creation, confirmation message, operator notification, and smart list.
```

## Prompt 8: Activation QA

```text
Create a QA checklist for partner activation assets. Include resource vault access, onboarding lessons, starter kit, activation messages, support form, operator notification, and dummy contact test.
```
