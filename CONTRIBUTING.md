# Contributing

## Purpose

This repository is a working platform playbook. Contributors should keep documents practical, linked, and easy for both people and AI tools to use.

## Document Standard

Every implementation document should include:

- Objective
- Asset name
- Dependencies
- Build steps
- Ask AI prompt when useful
- QA checklist
- Review items

## Naming Standard

Follow:

`OHRx | [Category] | [Function] — [Descriptor]`

## Review Standard

Before marking an asset ready:

- Confirm naming convention.
- Confirm links work.
- Confirm message tone matches brand voice.
- Confirm review-only terms are not public.
- Confirm QA checklist is complete.

## Pull Request Standard

Each PR should include:

- Summary
- Files added or changed
- Review items
- Testing completed
- Remaining work

## AI Contributor Rule

AI tools should update `PROJECT_STATUS.md` and `CHANGELOG.md` whenever they materially change the playbook.
