# Partner Campaign Setup

## Objective

Configure the native GHL partner campaign area for approved partners.

## Asset Name

`OHRx | Partner Program | Campaign Setup`

## Build Steps

1. Open the OurHealth Rx GHL sub-account.
2. Open the partner campaign area.
3. Create `OHRx Partner Program`.
4. Connect the application funnel.
5. Keep program terms as review items until approved.
6. Add one test contact.
7. Confirm the test contact receives a unique link.
8. Confirm the link sends visitors to the correct page.

## Ask AI Prompt

```text
Create a GHL setup checklist for the OHRx Partner Program campaign. Include campaign creation, link setup, application funnel connection, review items, and test steps. Do not invent final program terms.
```

## Done When

- Campaign exists.
- Funnel is connected.
- Test contact link works.
- Review items are clearly marked.
