# Approval and Link Management

## Objective

Define the approved partner handoff from pipeline review to active link delivery.

## Lifecycle

1. Applicant submits form.
2. Operator reviews contact record.
3. Operator moves opportunity to Approved.
4. Workflow adds approved tag.
5. Contact is added to campaign area.
6. Unique link is generated or assigned.
7. Link is delivered by email.
8. Resource access is granted.

## Manual Controls

- Do not approve from email alone.
- Review social fields before approval.
- Confirm payout/contact fields are complete.
- Confirm disclosure agreement checkbox exists.

## Ask AI Prompt

```text
Create a GHL approval checklist for a partner program. Include contact review, required fields, pipeline movement, campaign add step, link delivery step, resource access step, and QA test.
```

## QA

- Test contact moves from Applicant to Approved.
- Approved tag applies.
- Link is generated or noted.
- Approval message sends.
- Resource access message sends.
