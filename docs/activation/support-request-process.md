# Partner Support Request Process

## Objective

Define how approved partners ask for help and how the team routes support requests in GHL.

## Support Request Form

Asset name:

`OHRx | Form | Partner Support Request`

Fields:

- Name
- Email
- Phone
- Support category
- Question or request
- Link to post or screenshot if relevant

## Support Categories

- Link help
- Resource help
- Content question
- Account update
- Other

## Workflow

Trigger: support form submitted.

Actions:

1. Add support tag.
2. Create task.
3. Send confirmation message.
4. Notify operator.
5. Move to support smart list.

## Ask AI Prompt

```text
Create a partner support request process in GHL. Include support form fields, support categories, workflow trigger, tag, task creation, confirmation message, operator notification, and smart list.
```

## QA

- Form submits.
- Task is created.
- Confirmation message sends.
- Operator receives notification.
