# Partner Funnel Build Spec

## Objective

Build a three-page GHL funnel that moves visitors into the partner application process.

## Pages

1. Landing Page
2. Application Page
3. Confirmation Page

## Landing Page Sections

- Hero
- Why join
- How it works
- Who it is for
- Program value
- FAQ
- Final CTA

## Primary CTA

`Apply to Become a Partner`

## Application Page

Embed the current approved partner application form.

## Confirmation Page

Confirm receipt, set expectations, and direct applicant to check email and SMS.

## Ask AI Prompt

```text
Create a three-page GHL partner application funnel for OurHealth Rx. Pages: landing page, application page, confirmation page. Tone: clear, bold, trustworthy, community-centered. Include hero, why join, how it works, who it is for, program value, FAQ, and final CTA. Embed the partner application form on page two.
```

## QA

- All buttons point to application page.
- Form submits.
- Confirmation page loads.
- Mobile view is clean.
- Review-only terms are not visible.
