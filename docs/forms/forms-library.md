# Forms Library

## Objective

Define the required GHL forms for Sprint 2.

## Form 1: Partner Application

Asset name:

`OHRx | Form | Partner Application`

Fields:

- First Name
- Last Name
- Email
- Phone
- Instagram Handle
- TikTok Handle
- Facebook Page
- Website
- Audience Size
- Primary Niche
- City / State
- Why do you want to join?
- How do you plan to promote?
- Payout Email
- Agreement Checkbox

Required:

- Name
- Email
- Phone
- Audience Size
- Primary Niche
- Promotion Plan
- Agreement Checkbox

## Form 2: Partner Profile Update

Purpose: allow approved partners to update social links, payout email, and niche.

## Form 3: Partner Support Request

Purpose: route support questions into tasks.

## Form 4: Resource Request

Purpose: request missing graphics, scripts, or campaign material.

## Ask AI Prompt

```text
Create GHL forms for a partner program: application, profile update, support request, and resource request. Use clear field labels, required fields where appropriate, and simple confirmation messages.
```

## QA

- Each form submits correctly.
- Required fields work.
- Form submissions create contact activity.
- Each form can trigger the correct workflow.
