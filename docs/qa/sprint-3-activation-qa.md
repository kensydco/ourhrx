# Sprint 3 Activation QA

## Objective

Test resource vault, onboarding, starter kit, and activation workflows before use.

## Resource Vault

- [ ] Vault exists.
- [ ] Approved contact can access.
- [ ] Unauthorized contact cannot access if gating is enabled.
- [ ] Links and downloads work.
- [ ] Start Here section is visible.

## Onboarding Lessons

- [ ] Lesson order is correct.
- [ ] Each lesson has one clear action.
- [ ] Lessons are mobile-friendly.
- [ ] Review-only terms are not visible.

## Starter Kit

- [ ] Captions include link placeholder.
- [ ] Disclosure examples are visible.
- [ ] Contact templates are short.
- [ ] FAQ content is simple.

## Activation Sequence

- [ ] Sequence starts only after approval.
- [ ] Day 0 message sends.
- [ ] Day 1 reminder sends.
- [ ] Day 3 email sends.
- [ ] Day 5 email sends.
- [ ] Day 7 email sends.
- [ ] Day 10 SMS sends if allowed.
- [ ] Day 14 review sends.

## Support Request

- [ ] Support form submits.
- [ ] Task is created.
- [ ] Operator notification sends.
- [ ] Confirmation message sends.

## Exit Criteria

Sprint 3 is ready when a dummy approved contact can receive resource access, complete onboarding messages, use starter content, and submit a support request.
