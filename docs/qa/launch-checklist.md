# QA Launch Checklist

## Objective

Verify Sprint 2 assets before launch.

## Foundation

- [ ] Pipeline exists.
- [ ] Tags exist.
- [ ] Custom fields exist.
- [ ] Smart lists exist.
- [ ] Naming conventions are followed.

## Form

- [ ] Application form loads.
- [ ] Required fields work.
- [ ] Submission creates or updates contact.
- [ ] Submission is visible in contact activity.

## Funnel

- [ ] Landing page loads.
- [ ] CTA buttons work.
- [ ] Application page loads.
- [ ] Confirmation page loads.
- [ ] Mobile layout is clean.
- [ ] SEO title and description exist.

## Campaign

- [ ] Campaign exists.
- [ ] Test contact can be added.
- [ ] Test link works.
- [ ] Final terms are not published until reviewed.

## Workflows

- [ ] Application submitted workflow works.
- [ ] Pending information workflow works.
- [ ] Approval workflow works.
- [ ] Rejection workflow works.
- [ ] Resource access workflow works.
- [ ] Inactivity workflows are not active until tested.

## Messaging

- [ ] Email templates reviewed.
- [ ] SMS templates reviewed.
- [ ] Merge fields work.
- [ ] Links work.
- [ ] Messages use approved voice.

## AI

- [ ] Knowledge base loaded.
- [ ] Conversation AI tested.
- [ ] Phone AI tested if enabled.
- [ ] Escalation path works.
- [ ] AI does not invent terms.

## Launch Approval

- [ ] Owner review complete.
- [ ] Test contact completed full path.
- [ ] Recruitment content points to correct URL.
- [ ] Backup manual process is documented.
