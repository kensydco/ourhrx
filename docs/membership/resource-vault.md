# Partner Resource Vault

## Objective

Create a gated GHL resource area for approved partners.

## Asset Name

`OHRx | Membership | Partner Resource Vault`

## Access Rule

Only contacts with resource access should receive the vault link.

## Recommended Sections

1. Start Here
2. Program Basics
3. Disclosure Guide
4. Approved Starter Messages
5. Social Captions
6. Short Video Scripts
7. Image and Logo Assets
8. FAQ
9. Support Request Link
10. Updates

## Start Here Content

Approved partners should complete these first actions:

1. Save their unique link.
2. Read the disclosure guide.
3. Copy one approved starter message.
4. Share using the correct link.
5. Track responses and questions.

## Resource Types

- Captions
- DM scripts
- FAQ answers
- Short video scripts
- Canva links
- Logo files
- Image prompts
- Launch checklist

## Ask AI Prompt

```text
Create a GHL membership or gated page structure for an approved partner resource vault. Include sections for start here, program basics, disclosure guide, starter messages, social captions, short video scripts, image assets, FAQ, support request link, and updates. Keep the content simple and action-oriented.
```

## QA

- Access link works.
- Unauthorized contacts cannot access if gating is enabled.
- Approved test contact receives the vault link.
- Vault links and downloads work.
- Disclosure guide is visible before swipe copy.
